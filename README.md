# PulseTurf

Med spa competitive intelligence SaaS. Every Monday morning, paying users get an email with how their Google reviews compare to their top competitor: rating shifts, new reviews, what clients are saying. No dashboard, no app — the email is the product.

I built this end-to-end (Phases 0–6) and shipped it: Laravel 12 + Livewire 3, Outscraper for review scraping, GPT-4o-mini for digest generation, Stripe Cashier for billing, Resend for email. Live mode, payment ready, signed-URL feedback links. Then I cold-emailed med spa owners for a few weeks, got effectively zero conversions, and shut the servers down. Keeping the repo public as a record of what gets built when you actually try to ship a SaaS solo, including the parts that don't work.

## Features

- Onboarding wizard that finds a business via the Outscraper API and lets the user select up to 3 competitors
- Queued scrape jobs with retry, exponential backoff, and 4xx fail-fast
- Weekly digest generated by OpenAI GPT-4o-mini with HTML sanitization and template-based fallback on API failure
- Markdown email digests via Resend with signed-URL feedback links (👍 / 👎)
- Stripe billing via Laravel Cashier: 14-day trial, monthly + annual on Starter ($29 / $290) and Pro ($79 / $790)
- Webhook handler for `invoice.payment_failed` and `customer.subscription.deleted`, sends notifications, syncs DB state
- Trial reminder emails at 2 days, 1 day, and expired
- Plan-aware competitor limit enforcement (Pro=3, Starter/trial=1)
- Polymorphic `reviewable` and `scrapeable` so Business and Competitor share the same review/log infrastructure
- Settings page with Account + Billing tabs, Stripe Elements preserved across tab switches via `wire:ignore.self`
- Atomic idempotency on digest sends (`UPDATE WHERE status != 'sent'`)
- Idle-friendly: scheduled commands run from a single cron entry, queue worker via Supervisor

## Setup

### Prerequisites

- PHP 8.4 (Herd or equivalent)
- Composer
- Node.js v18+
- MySQL 9
- Outscraper, OpenAI, Stripe, and Resend accounts

### Install

```bash
composer install
npm install
```

### Environment

Copy `.env.example` to `.env` and fill in the API keys. Then:

```bash
php artisan key:generate
php artisan migrate
php artisan db:seed
```

The seeder creates a demo account: `demo@pulseturf.com` / `password`.

### Run

```bash
php artisan serve
npm run dev
php artisan queue:work
```

Visit `http://localhost:8000`.

### Scheduled jobs

Production runs on Laravel Forge with Supervisor for the queue and a single cron entry for the scheduler. The schedule fires:

- `digest:weekly` (Sunday 00:00 UTC) — chains scrape → generate → send for every active subscriber
- `trial:reminders` (daily 09:00) — sends 2-day, 1-day, and expired trial notifications

## Architecture Notes

- The OpenAI integration has a hard fallback: any `OpenAIException` swaps in a deterministic template-based digest so the Monday-morning email never fails to land. AI output is passed through `strip_tags()` with an allowlist before it ever reaches an email body.
- `OutscraperService` and `DigestGeneratorService` both throw typed exceptions (`OutscraperException`, `OpenAIException`) with static factories rather than passing strings around. Easier to test and easier to handle at the call site.
- Polymorphic relations (`reviewable`, `scrapeable`) let Business and Competitor share the review and scrape-log tables without table-per-type duplication.
- `EnsureSetupComplete` middleware is null-safe so a user mid-onboarding always lands on the right wizard step instead of a 500.
- All notifications implement `ShouldQueue` and use the MailMessage builder pattern for testability.
